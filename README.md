# E39 Finder

An offline-first tool for evaluating used BMW E39 Touring listings.

## Provisional scoring — version 1

| Category | Assessment | Points |
|---|---|---|
| Price relative to condition | Good / fair / poor | 25 / 15 / 0 |
| Structure | Sound / surface rust / repairs needed | 25 / 18 / 5 |
| Maintenance history | Documented / seller claim / limited | 20 / 8 / 0 |
| Mechanical condition | Healthy / minor issues / significant repairs | 15 / 8 / 0 |
| Mileage | Up to 270,000 / up to 320,000 / above 320,000 km | 5 / 3 / 1 |
| Remaining HU | At least 12 / at least 6 / under 6 months / expired | 5 / 3 / 1 / 0 |
| Modifications | Original / minimal documented / extensive or undocumented | 5 / 3 / 0 |

Maximum: 100 points.

These weights are provisional judgments, not market-validated predictions.
Mileage alone never disqualifies a vehicle.

## Unknown information

Unknown categories receive no awarded points and remain explicitly flagged.
An incomplete score is a minimum based on available information.

If any mandatory check or scoring category is unknown, the verdict is
INVESTIGATE unless a confirmed mandatory disqualification requires PASS.

Seller claims receive partial maintenance credit but must be labelled
as unverified.

## Verdicts

Confirmed mandatory disqualification: PASS, regardless of score.

Otherwise, when all required information is available:
- 70–100: CANDIDATE
- 55–69: INVESTIGATE
- Below 55: PASS

CANDIDATE means worth further consideration and inspection.

## Consistency

A confirmed severe structural or major mechanical defect always overrides
a more favourable general condition selection.

"Repairs needed" alone does not establish the severity of a defect.
Unclear severity requires investigation.

## HU calculation

Calculate remaining HU using calendar months.
HU remains valid throughout its stated expiry month.

## Price assessment

Price relative to condition is a manual assessment in version 1.
An asking price within the preferred budget does not automatically earn points.
Advertised prices are not assumed to be final sale prices.
